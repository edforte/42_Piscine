# 42 Piscine

Exercises from my **Piscine** at 42 Roma Luiss (September–October 2023): the four-week intensive selection that gives access to the 42 Common Core.

Each `cXX` folder is one day of C exercises; the percentage in the folder name is the grade obtained.

| Folder | Topics |
| --- | --- |
| c00 | `write`, first functions |
| c01 | Pointers |
| c02 | Strings |
| c03 | String comparison and concatenation |
| c04 | Number conversion (`atoi`, bases) |
| c05 | Recursion |
| c06 | `argc` / `argv` |
| c07 | Dynamic memory allocation |
| c08 | Header files, macros, structures |

These are my very first steps in C, kept as a record of where I started.
